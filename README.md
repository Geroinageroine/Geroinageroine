## CV

Использую **Python** для анализа данных.
Для мониторинга моделей **MLflow**.
Для заполнения данных и представления результатов по ML - **Streamlit**.

Для автоматизации использую **Apache Airflow**.

Храню данные в **ClickHouse** и **PostgreSQL** , **MSSQL**, **Garage S3**

Для визуализации и создания дашбордов применяю **Superset**

Работаю над совместными проектами через **Gitlab** и **Gitlab CI**.

Приложения складываю в **Docker** контейнеры.

На основании результатов **A/B тестирования** могу сделать выводы о наилучшей версии продукта

Знаю основные понятия **теории вероятностей**. Обладаю опытом проведения **статистических тестов**, предсказания цены на основании линейных моделей, а также владею методами **бутстрэп-анализа**.
